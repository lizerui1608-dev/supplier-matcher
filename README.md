# 供方智选：供应商匹配与评估

一个用于演示采购寻源初筛流程的本地原型。用户可导入供应商 CSV 或 Excel，输入采购需求并筛选品类、服务区域；系统结合文本相关度和可调整的采购指标权重生成候选排序，并显示规则风险提示。

项目不调用大语言模型，不代表真实中标概率，也不替代资质审查、采购审批或定标。仓库内所有供应商数据均为虚构样例。

## 功能

- 支持 CSV 与 Excel 工作簿（.xlsx）导入；Excel 可选择工作表。
- 检查必需字段、表头重复、空名称、非数字值和评分范围；无效行会被跳过并在页面提示数量。
- 支持按品类和服务区域筛选候选供应商。
- 使用字符级 n-gram TF-IDF 与余弦相似度计算采购需求和供应商描述的字面相关度。
- 支持配置需求匹配、价格、质量、准时交付率、合规和交期权重。
- 支持调整合规、准时交付率和质量的规则风险阈值。
- 展示综合分、分项指标、排序依据和风险提示，并导出排序结果 CSV。

## 本地运行

需要 Python 3.10 或更新版本。

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 Streamlit 显示的本地地址即可。macOS/Linux 可使用 `source .venv/bin/activate` 激活虚拟环境。

## 数据格式

CSV 或 Excel 工作表首行须包含以下列名：

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| `supplier` | 供应商名称 | 必填 |
| `category` | 供应商品类 | 必填 |
| `regions` | 服务区域 | 多个区域用分号分隔，例如“深圳;东莞” |
| `products` | 产品或服务描述 | 文本 |
| `certifications` | 资质描述 | 文本；系统不会核验资质真伪或有效期 |
| `unit_price` | 参考单价 | 数字，非负；同一比较范围内应使用可比单位 |
| `quality_score` | 质量分 | 0–100 |
| `on_time_rate` | 准时交付率 | 0–100 的百分数值，例如 95 表示 95% |
| `compliance_score` | 合规分 | 0–100 的输入分值，不是自动合规审查结果 |
| `lead_days` | 交期天数 | 非负数字 |

空值或不符合规则的数值行会从本次评估中排除，并显示跳过数量。若所有行都无效，系统会停止评估并提示修正数据。模板见项目目录中的 `suppliers.csv`。

## 评分逻辑

### 文本相关度

将每家供应商的品类、服务区域、产品描述和资质描述拼成文本，与用户输入的采购需求比较。程序使用字符级 2–4 gram TF-IDF 向量和余弦相似度，将相似度换算为 0–100 的需求相关度分。

这是字面文本相似度方法，不理解同义词、上下文或真实采购意图。低分不一定表示业务不匹配，高分也不代表供应商一定合格。

### 指标分和综合分

- 价格：在当前已筛选候选集合内归一化，价格越低分越高。
- 交期：在当前已筛选候选集合内归一化，天数越少分越高。
- 若当前候选全部同价或同交期，该项统一记为 100 分。
- 质量、准时交付率、合规分直接使用输入的 0–100 数值。
- 综合分为各项分数按用户权重计算的加权平均；权重总和必须大于 0。

因此，价格和交期分只能在当前筛选范围、计价单位可比的候选中解释，不适合跨品类直接比较。默认权重是演示配置，并非通过历史采购结果训练或验证。

### 风险提示

合规、准时交付率和质量的提示阈值可在页面调整。风险提示是阈值规则，不是预测模型；程序不会核验证照真伪、证书有效期、关联关系或真实履约记录。

## 数据与使用边界

- 示例供应商和评分全部为虚构内容，不对应真实企业或交易。
- 上传文件仅用于当前本地应用会话；请勿上传未经授权的供应商资料或个人信息。
- 当前为单机演示原型，不含用户登录、权限管理、数据库、审计日志或采购系统集成。
- 排序只用于辅助初筛。正式采购应根据公司制度核验原始证照、报价、税费、服务范围和履约记录，并由有权限人员作出决定。

## 后续方向

可基于获得授权且已脱敏的数据，补充硬性准入与一票否决规则、资质有效期管理、历史履约数据和人工复核记录。若要判断文本匹配是否有效，应建立人工标注的需求—供应商样本，与关键词基线及其他方法比较 Precision@K、Recall@K 或 NDCG@K；在完成验证前，不应把当前分数解释为准确率或中标概率。
