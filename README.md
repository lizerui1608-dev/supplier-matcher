# 供方智选：供应商匹配与评估

一个结合供应商管理实习场景制作的本地个人项目原型。流程围绕“资源池筛选—资格初筛—能力指标评分—候选排序与风险提示”，帮助演示如何把供应商初筛步骤整理成可重复查看的流程。

开发过程中使用 AI 编程助手辅助拆解需求、搭建和迭代原型；应用运行时不调用大语言模型 API。文本匹配采用传统 NLP 的字符级 TF-IDF 和余弦相似度。项目样例数据均为虚构数据，不来自雇主或真实采购交易；项目未接入任何企业采购系统。

## 项目流程

1. **资源池筛选：**按供应商品类和服务区域筛选候选名单。
2. **资格初筛：**根据表格中人工录入的资格状态、经营范围匹配和黑名单标记执行硬性过滤。不通过或待核验的记录不进入后续能力评分，并展示排除原因。
3. **能力与履约指标比较：**对通过资格字段筛选的候选，结合需求文本相关度、价格、质量、准时交付率、合规分和交期计算加权得分。
4. **人工复核：**展示分项指标和规则风险提示，支持导出当前候选的排序结果，供采购人员进一步核验。

## 功能

- 支持 CSV 和 Excel 工作簿（.xlsx）导入，Excel 可选择工作表。
- 检查必需字段、空名称、非数字值和评分范围；无效数据行会提示并跳过。
- 按品类、服务区域过滤资源池。
- 资格初筛状态支持“通过/不通过/待核验”；经营范围支持“是/否/待核验”；黑名单字段支持“是/否/待核验”。
- 对通过资格字段筛选的记录进行文本相关度计算和多指标加权排序。
- 可调整权重与质量、准时交付率、合规分的风险提示阈值。
- 显示未进入评分的记录及原因，导出已筛选候选的排序结果 CSV。

## 本地运行

需要 Python 3.10 或更新版本。

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 Streamlit 显示的本地地址即可。macOS/Linux 可使用 `source .venv/bin/activate` 激活虚拟环境。

## 数据字段

CSV 或 Excel 工作表的首行需包含以下字段。可复制并扩展 `suppliers.csv` 模板。

| 字段 | 含义和格式 |
| --- | --- |
| `supplier` | 供应商名称，必填 |
| `category` | 品类，必填 |
| `regions` | 服务区域，多个区域以分号分隔，例如“深圳;东莞” |
| `products` | 产品或服务描述文本 |
| `certifications` | 资质描述文本 |
| `qualification_status` | 人工初审状态：通过、不通过、待核验 |
| `scope_match` | 经营范围与拟合作业务是否匹配：是、否、待核验 |
| `blacklisted` | 是否标记为黑名单：是、否、待核验 |
| `unit_price` | 非负数字；相互比较的候选应使用可比计价单位 |
| `quality_score` | 0–100 的质量分 |
| `on_time_rate` | 0–100 的准时交付率，例如 95 表示 95% |
| `compliance_score` | 0–100 的输入评分 |
| `lead_days` | 非负交期天数 |

资格字段中的空值或不识别的值会归为“待核验”，不会默认通过。数据校验仅检查格式，不会核验营业执照、资质证书、信用信息、关联关系或黑名单原始记录。

## 评分逻辑

字符级 2–4 gram TF-IDF 对品类、服务区域、产品和资质描述与采购需求做字面相关度比较。余弦相似度换算为 0–100 的需求相关度分。它不理解同义词和上下文，不是准确率或中标概率。

价格和交期分别在当前已通过资格、品类和服务区域筛选的候选集合内做 0–100 归一化；越低的价格或越短的交期得分越高。若当前集合内所有候选该指标相同，则该项统一记为 100 分。质量、准时交付率和合规分采用表格中的输入值。综合分为各指标按可调权重计算的加权平均，权重总和必须大于 0。

风险提示使用页面中可调整的阈值规则，不是 AI 预测，也不替代采购制度规定的审核或审批。

## 项目边界

- 资格初筛依赖人工录入状态，程序只执行字段规则，不做材料真实性审查。
- 能力评分是演示用的启发式排序，权重和风险阈值没有用历史采购数据校准。
- 价格和交期是当前候选集合内的相对分数，不适合跨品类或计价单位不一致的场景比较。
- 当前没有审批流、证照有效期管理、履约档案、用户权限、审计日志或采购系统集成。
- 所有演示记录为虚构供应商数据。正式采购仍需按组织制度完成资格与能力审核、资料留档、履约评估和人工决策。

该原型抽象的是供应商资源池、资格与能力分阶段审查、履约指标比较等通用管理思路，不复制雇主内部审批层级、阈值、名单或供应商资料。
